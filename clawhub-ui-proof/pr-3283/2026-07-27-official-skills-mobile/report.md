# Official skills mobile browse

The baseline captures the production route at `https://clawhub.ai/skills?tab=official`
in a 390 by 844 mobile viewport. The selected Official feed renders an empty state.

The candidate captures the same route on a real local ClawHub instance using the
legacy rollout capability. The deterministic `catalog-atlas` official publisher
fixture renders `1688-shop-health-check` in the Official feed.
